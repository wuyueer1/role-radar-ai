## 自动化验证

运行：

```bash
cd site
npm run test:all
```

覆盖：

- 策展数据无悬空角色、技能、证据、边或路径；
- 权重自动归一与重平衡，总和严格为 1；
- 评分确定、0–100 有界，并对情景预设作出响应；
- 每条推荐包含优势、缺口和简历证据；
- 90 天计划包含三个有序阶段和具体证据目标；
- Live AI 非法结构安全降级且保留原始文本；
- 生产构建和服务端渲染；
- Open Graph/Twitter 封面使用请求主机生成绝对 URL；
- 整页画像、图谱聚焦、权重重排、抽屉、模式说明与五步讲解交互。

最近结果：领域/SSR/依赖来源 9 项、组件交互 5 项，共 14 项通过。
