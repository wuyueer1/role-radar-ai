# CareerGraph AI 验证记录

验证日期：2026-07-29

## 自动化验证

运行：

```bash
cd site
npm run test:all
```

覆盖：

- 策展数据无悬空角色、技能、证据、边或路径；
- 权重自动归一与重平衡，总和严格为 1；
- 评分确定、0–100 有界，并对情景预设作出响应；
- 转型速度同时考虑目标岗位准备时长、时间窗和候选人技能缺口；
- 情景解释指出主导权重/组件变化以及排序位次移动；
- 每条推荐包含优势、缺口和简历证据；
- 90 天计划包含三个有序阶段和具体证据目标；
- Live AI 非法结构安全降级且保留原始文本；
- Live AI 空摘要/空技能结构会被 schema gate 拒绝；
- 生产构建和服务端渲染；
- Open Graph/Twitter 封面使用请求主机生成绝对 URL；
- 整页画像、图谱聚焦、边缘角色探索、权重重排、抽屉焦点、Live AI 可见降级与五步讲解交互；
- Service Worker 注册与离线导航缓存。

最近结果：领域/SSR/依赖/离线 12 项、组件交互 6 项，共 18 项通过；Playwright 桌面与紧凑视口端到端 2 项通过。

## 浏览器功能验证

已手动完成：

- `最大化技术深度` 更新权重并触发路径重排；
- 路径变化原因同时显示主导权重与前后位次；
- 图谱节点可以聚焦和恢复；
- 不在三条主路径中的 `AI 应用工程师` 仍保持聚焦，并展示关键技能与证据缺口；
- 证据抽屉的 4 个标签均可打开；
- 0–30、31–60、61–90 天计划完整；
- 模型边界弹窗可现场验证 Live AI 失败后原文保留和稳定降级；
- 5 步三分钟讲解可前进并正常完成；
- 第 5 步在单一弹窗内预览三阶段计划，不产生叠加 dialog；
- 自动化浏览器断网刷新后仍能恢复核心工作台。

## 可访问性与现场稳定性

- 页面语言为 `zh-CN`；
- 主要区域有具名 landmark；
- 交互元素使用 button、slider、tab、dialog 等语义；
- 有跳到主要内容链接；
- 键盘焦点有可见样式；
- 三类 dialog 均有初始焦点、Tab 焦点圈和 Escape 关闭，背景内容使用 `inert` 隔离；
- 尊重 `prefers-reduced-motion`；
- 不依赖远程字体、浏览器密钥或数据库；
- 默认稳定模式无需模型、密钥或数据库；首次载入后可断网刷新并完成核心流程。

## 数据与声明检查
